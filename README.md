# Markdown to HTML Converter

A simple frontend project that converts Markdown syntax into HTML using JavaScript. It also displays a live preview of the converted content.

## Features

- Convert Markdown headings (`#`, `##`, `###`) into HTML headings.
- Convert images and links into HTML elements.
- Support bold and italic text formatting.
- Convert blockquotes into HTML blockquote elements.
- Display the generated HTML.
- Show a live preview as you type.

## Built With

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the project in your browser.
2. Enter your Markdown content in the input area.
3. View the generated HTML in the output section.
4. Check the live preview of the converted content.

## What I Learned

Through this project, I practised JavaScript string manipulation, regular expressions, the `replace()` method, DOM manipulation, event listeners, and updating HTML content dynamically.

## Project Goal

The goal of this project was to gain more practical experience with JavaScript by building a tool that converts Markdown syntax into HTML.
